# 🌿 HomeoAssist — Healthcare Platform for Homeopaths

**HomeoAssist** is an intelligent, clinical-grade digital platform designed to bridge homeopathic practitioners with modern AI diagnostic support, streamlined triage pipelines, and automated case management.

Developed as a project for **North South University • Dhaka, Bangladesh**.

---

## ✨ Key Features

- 🤖 **AI Symptom Intake:** Conversational symptom logging that translates patient language into structured repertory entries.
- 🩺 **Intelligent CDSS:** Clinical Decision Support System calculating remedy probability match metrics.
- 🚨 **Emergency Triage Routing:** Real-time multi-doctor emergency call routing protocols.
- 🔐 **Multi-Role Access Control:** Custom portals tailored for **Patients**, **Certified Doctors**, and **System Administrators**.
- 📜 **QR-Verified Prescriptions:** Secure dispensation tracking with embedded verification codes.

---
